# Cloudflare Workers Deployment (Backup)

Primary deploy: **Lovable Publish** → https://yasin-os.lovable.app
Backup: **Cloudflare Workers** (via auto-generated wrangler config)

## কীভাবে কাজ করে

`@cloudflare/vite-plugin` build-এর সময় নিজেই `dist/`-এর ভেতর একটি সঠিক
`wrangler.json` জেনারেট করে — Worker bundle + static assets সহ। তাই
project root-এ আলাদা `wrangler.jsonc` রাখার দরকার **নেই** (রাখলে path
mismatch-এ build fail করে — যেটা আগে হয়েছিল)।

## Cloudflare Pages/Workers Dashboard সেটআপ

**Workers & Pages → Create → Connect to Git** → repo `yasin-os` select:

- **Framework preset**: None
- **Build command**: `bun install && bun run build`
- **Deploy command**: `npx wrangler deploy --config dist/*/wrangler.json`
  - (অথবা first build-এর পর exact path দেখে নিন, যেমন
    `dist/tanstack_start_ts/wrangler.json`)
- **Root directory**: `/`
